# AI 分课学习使用与验证

## 使用入口

- 学习：先介绍基础和目标，完成 24 道逐题测评。测评结束后只读归档，主动开启第一课。
- 新一课自动生成文章与词表。阅读并完成本章闯关后，返回学习页继续讲解和练习。
- 教练确认达到试卷阶段后，依次生成阅读材料、5 道阅读题、完型材料、10 道完型题、4 道翻译题（英汉各 2 道）。成功步骤立即保存，中断后点击继续生成。
- 点击开始答卷，在阅读页作答。选择、填空和翻译答案自动保存；提交后答案冻结，整卷由 AI 批改。失败可重新批改原答卷。
- 错题涉及的每个知识点都需要答对一道新同类题，才会完成本课。原题重答、试卷前的练习不作为错题复测证据。全对卷直接完成。
- 完成本课才能手动开启下一课。第 3、6、9……课为复习课。
- 书架：AI 学习初始 0 章，课程文章、试卷自动归入该书。课程关联章节不能单独编辑、删除。
- 自建书：添加章节时可选“文章与题目”，按部分添加材料、选择题、填空题和双向翻译题，填写参考答案、解析和知识点。
- 我的 → 长期学习记忆：查看已掌握、待巩固、已学文章摘要，并修改个人情况和学习目标。
- 原文章阅读中成功查到单词释义后自动加入生词本；重复查询去重。

## 数据与恢复

所有数据继续保存在本机。旧版教练代码、推荐计划与对话迁移已移除。启动时自动清理旧学习记录及此前迁移的旧版对话；恢复备份也不会带回这些内容。新版课程、书籍、生词与笔记保留。共享长期记忆与各会话记录分开。聊天分页展示，本地历史不删除；模型接收本课累计摘要、练习证据和近期消息。

备份版本升级为 4，包含课程、记忆、生成进度、草稿和提交答案。恢复时校验章节关联、批改题号和课程通过证据；清理缓存不会清除学习数据。云同步不在本次范围内。

## 验证

- `npm run check`：TypeScript 检查、39 项自动化测试、构建到 dist。
- `npm run verify:templates`：15 个 WXML 与 16 个 WXSS 通过微信原生编译器。
- 新增测试使用模拟模型响应覆盖：自我介绍与测评、只读归档、分步生成及失败恢复、试卷批改缺项、全对完成、错题逐点解锁、备份完整性、隔离对话、复习编号、答题草稿恢复和提交冻结。
- `npm run preview:ui` 的 `/study`、`/exam`、`/memory` 提供浏览器外观样例。已查看试卷与学习页样例，不能替代微信运行时验证。
- 未使用真实模型 API 或微信真机完成端到端验证。上线前应实际走一轮测评与学习，检查模型出题质量、语义批改、网络耗时、输入法遮挡和设备布局。

新增业务实现均为 TypeScript。继续使用已配置的主模型端点，无新增第三方 API 域名。
