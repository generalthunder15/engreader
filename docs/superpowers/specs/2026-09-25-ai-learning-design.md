# AI 分课学习与交互试卷设计

日期：2026-09-25

## 已确认的目标

保留现有书籍、阅读、划词、词汇闯关和模型配置功能。新增交互题目章节、AI 专属书籍、独立学习对话、共享长期记忆，以及从测评到错题复测的完整学习流程。实现语言使用 TypeScript。

用户最新确认优先于此前方案：只有完成本课才能开启下一课；每个错题知识点必须答对至少一道新同类题；试卷顺序分段生成、可重试；整份试卷交给 AI 批改，允许翻译有多种正确表述。

## 学习流程与权限

首次使用：自我介绍 → 自适应测评 → 测评报告与初始长期记忆 → 测评会话只读归档。

自我介绍使用自由输入，引导描述当前基础、目标、薄弱点和学习时间。介绍不计入测评答题数。沿用现有 24 道测评题作为初始数量，每次只呈现一道题，难度参考介绍和此前回答。

用户主动开启每一课（2026-09-27 更新）：创建会话 → 生成文章并分步准备配套题目 → 阅读与单词闯关 → 解锁阅读页试卷 → 作答并提交 → AI 批改 → 错题讲解与同类题复测 → 完成本课。考前对话讲解与逐题练习已移除。

- 测评未结束不能开始第一课。
- 同时最多存在一个未完成的学习会话。所有新建入口均检查该条件。
- 生成失败、已交卷、批改失败、补学中，都不代表完成。
- 本课完成要求试卷批改成功，且所有错题知识点都有有效的同类新题答对记录。无错题时批改成功即可完成。
- 完成后不自动创建下一课，显示用户主动开启下一课的入口。已完成课保留只读记录。
- 测评归档后不能发送消息或继续答题；读取历史不改变当前学习进度。
- 聊天每次最多提出一道需要用户回答的练习题。完整试卷在独立答题区域展示。

## 章节与交互题目

章节区分 article（纯文章）和 exam（试卷），旧章节默认 article。使用有稳定 ID 的内容区块呈现文章、题干与题目，不从展示文本反向猜测题目。

题目支持 choice、fill、translation；翻译额外记录英译汉或汉译英。选择题使用可交互选项卡，填空和翻译在题干下放输入框。题目保存题干、选项、参考答案、解析、知识点和材料关联。提交前不在界面暴露参考答案和解析。

草稿按章节及题目 ID 保存。退出、返回或重启后恢复答案。完整试卷生成后才能提交；提交前提示未答题，不以空答案自动判完成。提交产生不可变的答案快照，批改重试使用同一快照。

阅读时保留划词等操作。单词翻译成功后自动加入生词本，包括缓存或词典返回的有效释义；查询失败不收录。按标准化词形去重，保留来源。整句翻译不把整句收录为单词。

## AI 专属书籍与生成

通过固定 ID 初始化一本“AI 学习”，初始为 0 章，重复启动不重复创建。每课生成的文章与试卷分别保存为章节，关联会话 ID 与课程编号。

普通课依据用户水平、薄弱点、已掌握知识和文章摘要生成新主题文章，替代推荐已有章节。每第 3、6、9……课为复习课：新文章重点覆盖已掌握知识。课程编号按已创建的有效课程顺序确定，重试不递增，不把试卷中的阅读材料计为新一课。

试卷初始规模采用此前建议：1 篇阅读理解、5 道阅读题；1 篇完型填空、10 空；4 道翻译，英译汉与汉译英各 2 道。阅读理解直接使用本课学习文章；完型与翻译围绕本课目标检验迁移能力。

文章生成后立即在对话中提供“去阅读文章”按钮，并继续准备题目。题目完成前及单词闯关完成前，不发布试卷章节到书籍目录，不开放作答；解锁同时检查生成完整性和闯关完成记录。

生成细分步骤：复用本课文章 → 逐道阅读题 → 完型材料（预留编号空位）→ 逐空选项与答案 → 逐道翻译题。顺序完成阅读、完型、翻译三个部分。每个成功步骤通过结构校验后立即持久化；重试只针对未完成步骤，保留已生成材料和题目。

生成请求带课程、章节、步骤标识；重复点击、延迟响应和重试不得造成重复章节或题目。退出页面后不假设请求能继续运行；再次进入从最后保存的步骤恢复。错误展示失败位置和重试入口。

整份试卷齐全前明确显示生成进度，不能把半成品标记为可提交试卷。保留文章单独生成与阅读的能力。

## 批改与错题补学

提交后将全部材料、题目、参考答案和用户作答交给 AI，要求按题目 ID 返回是否正确、反馈、参考解法和相关知识点。翻译按语义、表达和关键语法判断，不做逐字匹配。

程序校验结果覆盖所有题目、无重复或未知 ID、状态字段有效。格式错误或缺项时保留原答案并允许重新批改，不默认通过。AI 批改仍可能有误，反馈应展示判定依据。

将错误题目涉及的知识点合并为待补学集合，保留来源题目。逐个讲解并出新同类题，不直接重发原题。用户回答交给 AI 判定，正确后记录对应知识点的通过证据；错误则继续讲解并换题。一次一道题。所有待补学知识点均通过后，本课才能完成。

一道复测题只承担一个明确的待补学目标，避免模型一句“已掌握全部”跳过其他知识点。复测记录包含新题 ID、目标知识点、用户答案、批改结论和时间。

## 对话与记忆

每个会话独立保存消息、当前阶段、课程章节、练习和复测进度。测评会话与课程会话分开。对话列表显示类型、标题、阶段和完成情况，历史会话可查看。

共享长期记忆结构化保存用户情况、目标、已掌握知识点、薄弱点和已学文章的一句话摘要。知识掌握条目附答题证据和更新时间。AI 提交记忆更新建议，由程序合并，不允许用缺失字段覆盖整份历史。

同一课可在学习过程中更新记忆；完成时合并本课成果。生成过但未学习的文章不能记录为“已学”。复习课发现遗忘时允许降为薄弱点。不同课使用共享记忆，本课短期上下文不直接混入其他课的完整聊天。

“我的”增加长期记忆入口，按个人情况、已掌握、待巩固、已学文章分组显示；提供个人情况纠正入口。长对话保留完整本地历史，模型上下文采用本课摘要与近期消息，避免无限累加。

## 数据兼容与模块边界

沿用本机存储与现有备份机制，本次不增加云同步。升级不得删除已有书籍、生词、笔记、设置。旧单会话记录迁移为可查看的历史记录，旧用户画像保留为待整合资料，不凭旧推荐计划推断新课程已完成。迁移可重复执行且不会重复导入。

模型层扩展章节、题目、答卷、会话、记忆和生成任务结构。学习流程放在独立纯逻辑模块，集中校验阶段转换与解锁条件；AI 服务负责生成和结果解析；存储服务负责原子保存、迁移和恢复；页面负责交互和展示。

长期记忆、会话、答案和生成进度属于用户数据，不能被“清理可再生成缓存”删除。恢复备份需校验关联 ID，避免出现已解锁却没有试卷与通过证据的状态。

## 实施顺序与验收

1. 建立模型、迁移、流程状态与解锁规则。
2. 实现题目章节、答题草稿与提交快照。
3. 实现 AI 书籍和分步骤生成、失败恢复。
4. 实现介绍、测评归档、独立会话、教学与批改复测闭环。
5. 实现长期记忆页面、复习轮次和查词自动收录。
6. 进行集成验证与微信模板编译。

关键验收：未完成课不可新建；交卷不解锁；每个错题知识点均需新同类题通过；全对卷直接完成；第三课为复习课；生成任一步骤中断可恢复且不重复；批改缺项不能通过；翻译同义答案可接受；测评归档只读；会话上下文隔离；长期记忆共享；草稿重启恢复；旧数据迁移及备份恢复不丢失；重复查词不重复收录。

编译和单元测试不能代替微信实际布局验证。需要在开发者工具中检查选项卡、输入框、键盘遮挡、长试卷滚动、生成状态和历史对话展示。
