# 学习记忆与提示词重构

## 范围

保留测评、生成文章和配套试卷、单词闯关解锁、作答批改及错题复测。替换学习服务的旧提示词，阅读页的词典/拆解提示词不属于此次替换范围。学习状态和完成条件仍由程序控制。

## 调研与取舍

- Claude Code 官方文档把持续记忆用于用户角色/偏好、纠正反馈、进行中的工作与参考信息；Markdown 文件便于检查和修改。https://code.claude.com/docs/en/memory
- LangGraph 官方文档区分会话级短期记忆与跨会话长期记忆，并讨论窗口裁剪、摘要以及在线/后台更新的取舍。https://docs.langchain.com/oss/javascript/concepts/memory
- 本项目采用单份可读 Markdown 用户档案与结构化题答记录，不引入向量数据库。理由是个人英语学习数据规模小，明确要求应直接保留，不应依赖检索命中。

## 数据与上下文

`learning_v1` 保存会话和记忆。兼容已有键名，记忆内容改为 `markdown`，另有版本计数、更新时间与已汇总会话ID等应用元数据。这些元数据由程序维护，不要求模型输出 JSON 记忆。

UI 保留完整历史；模型上下文单独构建。短期记忆包含自述、题目/可见材料/选项、用户答案、对错事实、已分类的疑问与要求；不包含 AI 解析、系统通知、闲聊。较新完整题答保留约14000字符窗口，更早题答缩为索引（含题干、材料前300字符、选项和答案），有效要求固定保留并按新旧顺序传入。此预算是完整题答窗口预算，不是整个请求的严格 token 上限。

一条补充可同时包含疑问和要求，采用单独分类请求。先分类，再批改；分类失败时保留待答题与输入，不误记成绩。已过滤内容不会经原始 UI 消息或证据解析再次进入请求。旧版题答可以重建；旧版未分类补充不猜测其意图，不自动带入新上下文。

短期记忆按会话隔离。出题参考最新要求，批改参考当前疑问、作答思路与要求。题意只取可见题面，参考答案不能构成隐藏条件。

## 归档更新

测评完成归档或课程全部完成后，先持久保存成绩和只读状态，再将本会话题答分块概括为 Markdown 摘要，再合并旧 MEMORY.md 得到新文档。长短期不会每答一题同步。

总结可记录背景/目标、时间约束、兴趣、难度/讲解偏好、用户纠正、经历概要、待确认事项。标题不固定，不能编造未知信息、把临时要求当永久偏好、列词汇掌握清单，或把一次正确当永久掌握。

跨会话串行合并。重复归档幂等；摘要完成后缓存，重试合并无需再次批改。人工编辑和清数据期间，过期响应不能覆盖更新。失败保留旧文档和完成状态，学习页与记忆页提供重试；归档记忆更新完再开启下一课。

旧版迁移保留用户自述与已结束课程摘要，不导入词汇/知识点掌握清单，保留会话和试卷原始记录。已结束的旧会话标记为已迁移，避免升级时批量调用模型。未结束会话按新机制继续。

## 用户界面

“我的→长期记忆”直接显示 MEMORY.md 的 Markdown 正文，可选择文本、编辑和保存，不再显示掌握/薄弱知识点表。内容仍保存在小程序本地，尚未接云服务。这里的文档由本地存储保存，并非仓库内的用户数据文件。

## 验证

自动化覆盖不逐题更新、混合补充与噪声排除、分类失败重试、会话隔离、窗口外要求保留、归档失败/幂等、人工修改竞争、旧记录迁移和既有学习流程。真实模型调试脚本 `tools/check-learning-model.ts` 只接受进程环境变量 BAILIAN_API_KEY，使用虚构样例，不读写用户学习记录，不保存密钥。

验证结果：65项本地测试、TypeScript类型检查、构建及19份WXML/21份WXSS编译通过。最后一轮11次真实百炼请求覆盖混合补充、噪声过滤、过去时要求、多解题、分段文章、阅读、完型、英汉双向翻译和Markdown归档合并，样例检查通过。早期调试发现闲聊混入要求、无效题不返回grades、翻译方向及分段不稳定，已调整提示词和容错。模型样例通过不代表所有生成都必然正确；未完成真机界面验证（调试连接断开）。
