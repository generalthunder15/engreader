# 英语精读重写：功能与验收

用户已授权按功能整体重写，采用原生微信小程序 + strict TypeScript。WXML/WXSS 为视图，构建后的 JavaScript 仅存在于忽略的 dist 中。保留原页面路径、存储键与 v3 备份协议。

## 功能清单
- 书架：内置四级/考研读物，新建/删除书籍，章节列表、继续阅读。
- 章节：新增/编辑/删除，正文分句，B1 及以上词汇及短语提取，手动词表，分批句译与进度。
- 阅读：连续加载下一章、目录、前后章、进度、双击选词、长按整句、跨词选择、复制、划线、笔记及删除、收藏句子/章节。
- 精读：在线词典/备用词典/离线词库、AI 单词释义、整句翻译、语法、逐词详细拆解、建议问题和自由问答、加入生词本。
- 朗读：词典发音、免费合成、可选语音 Key、语速、缓存、停止、自动播放。
- 闯关：生词本最近 N 词、章节词表、补释义、随机选项、错词重练、完成统计及学习计划同步。
- 学习：24 道动态摸底、画像和对话持久化、书架章节计划、章节闯关后解锁问答、重置。
- 收藏：生词搜索/删除/发音、句子收藏/发音/删除、章节收藏/跳转/取消。
- 外观：浅色/护眼/夜间，系统/内置/导入字体、删除字体，字号、行距、缩进和界面字体同步。
- 设置：两组模型配置、朗读选项、闯关数量、本地兜底、手动网络自检、复制域名、缓存清理、备份恢复、两档清除数据。

## 设计
core 保存纯数据模型、分词、测验和阅读流；services 负责持久化、请求、AI、词典、音频、字体和主题；页面负责事件和展示。统一色彩、线性图标、卡片、表单、底部安全区和弹层。

不按地域判断服务可用性，正常功能直接请求配置接口。自检只报告实际连通性。保留格式与数据完整性校验。新安装不再内置凭据，已有用户设置保留。正常读取不清空用户数据；导入失败回滚；存储失败不报告成功。
